# Sonic Dr Robotnik Release Notes

Sonic Dr Robotnik is SonicDE's crash reporter: when an app crashes, it helps you understand what happened and report the problem.

## 6.8.2 (2026-11-10)

- Behind the scenes: updated the project logo.

## 6.8.0.1 (2026-10-23)

- The crash reporter window now always opens in a way that suits your current session, instead of copying a display setting from the app that crashed.

## 6.8.0 (2026-10-20)

- The crash reporter now uses one modern, consistent window in every mode, including safe and minimal modes.
- Fixed a possible crash in the crash reporter when sending a report.
- Behind the scenes: version update.

## 6.7.5 (2026-09-12)

- Behind the scenes: version update.

## 6.7.4.1 (2026-08-12)

- The crash reporter now recognizes Sonic Win, SonicDE's window manager, by its new name.

## 6.7.4 (2026-08-03)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.7.3.1 (2026-08-02)

- The crash reporter now works on any system, with or without systemd.

## 6.7.3 (2026-07-14)

- Behind the scenes: restored the code formatting settings and added support for developers' code-navigation tools.
